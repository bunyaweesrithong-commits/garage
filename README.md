# ระบบประวัติการซ่อมรถ + ใบรับรองการซ่อม (Google Apps Script)

ระบบสำหรับอู่ซ่อมรถ ใช้ **Google Sheet เป็นฐานข้อมูล** และ **Google Apps Script** ทำหน้าเว็บค้นหา/บันทึกประวัติ และพิมพ์ **ใบรับรองการซ่อมรถ** ได้ 2 แบบ

1. **หน้าพิมพ์ HTML (A4)**: กด 🖨 พิมพ์ แล้วสั่งพิมพ์หรือบันทึกเป็น PDF จากเบราว์เซอร์ได้ทันที
2. **Google Doc + PDF**: กด 📄 สร้าง Doc/PDF ระบบจะสร้างไฟล์ Google Docs (แก้ไขต่อได้) และ PDF เก็บไว้ใน Google Drive

## ฐานข้อมูล (Google Sheet)

**ชีต `Vehicles`: ข้อมูลรถและลูกค้า (1 แถว = รถ 1 คัน)**

| คอลัมน์ | ความหมาย |
|---|---|
| รหัสรถ | ID อัตโนมัติ (เช่น `V3F9A1C2B7D`) |
| ทะเบียน / จังหวัด | เช่น `กข 1234` / `กรุงเทพมหานคร` |
| ยี่ห้อ / รุ่น/โมเดล / สี | |
| เลขตัวถัง (คัสซี) | |
| ชื่อลูกค้า / เบอร์โทร | |
| ช่องทางติดต่ออื่น | LINE / Facebook / อีเมล ฯลฯ |
| หมายเหตุ, สร้างเมื่อ, แก้ไขล่าสุด | |

**ชีต `Repairs`: ประวัติการซ่อม (1 แถว = การซ่อม 1 ครั้ง, อ้างอิงรถด้วย `รหัสรถ`)**

| คอลัมน์ | ความหมาย |
|---|---|
| รหัสงานซ่อม, รหัสรถ | |
| **เลขที่/ปี** | เช่น `012/2569` คือรถคันที่ 12 ที่เข้าซ่อมในปี พ.ศ. 2569 (ออกเลขอัตโนมัติ) |
| ลำดับรถในปี, ปี (พ.ศ.) | ตัวเลขที่ใช้คำนวณเลขที่ถัดไป |
| วันที่รับรถ / วันที่ซ่อมเสร็จ | |
| เลขไมล์ (กม.) | |

| ช่างผู้รับผิดชอบ, ค่าใช้จ่าย, หมายเหตุ | |
| ลิงก์ใบรับรอง (Doc/PDF) | บันทึกอัตโนมัติเมื่อสร้างใบรับรอง |

รถ 1 คันจึงมีประวัติการซ่อมได้หลายครั้ง และค้นหาย้อนหลังได้ทั้งหมด

**ชีต `Settings`**: ชื่อร้าน ที่อยู่ เบอร์โทร เลขผู้เสียภาษี โลโก้ ข้อความรับรอง เงื่อนไขรับประกัน จำนวนหลักของเลขที่ ฟอนต์ โฟลเดอร์เก็บไฟล์ และแม่แบบ Google Doc

### กติกาเลขที่/ปี
- เลขที่มีรูปแบบ `ลำดับ/ปี พ.ศ. 2 หลัก` เช่น `99/69` และ**นับใหม่ทุกเดือนตามวันที่รับรถ**: รถคันสุดท้ายของกันยายนเป็น `99/69` คันแรกของตุลาคมเป็น `1/69`
- ตอนบันทึกการซ่อม ระบบจะใส่ลำดับถัดไปของเดือนให้ในช่อง **ลำดับรถคันที่** และแก้เองได้ เช่น ให้ตรงกับสมุดเดิม แต่ห้ามซ้ำกับงานอื่นในเดือนเดียวกัน (คันต่อไปจะนับต่อจากเลขสูงสุดของเดือน)
- เลขที่ออกแล้วจะไม่เปลี่ยนเมื่อแก้ไขงานซ่อม เพื่อให้ตรงกับใบรับรองที่พิมพ์ไปแล้ว
- ใช้ LockService กันเลขซ้ำเมื่อบันทึกพร้อมกันหลายเครื่อง
- ปรับได้ในแท็บ `Settings`:
  - `jobNoReset`: `month` = นับใหม่ทุกเดือน (ค่าเริ่มต้น), `year` = นับใหม่ทุกปี
  - `jobNoFormat`: `{n}` = ลำดับ, `{yy}` = ปี พ.ศ. 2 หลัก, `{yyyy}` = ปี พ.ศ. 4 หลัก, `{mm}` = เดือน เช่น `{n}/{yy}` → `1/69`, `{n}/{mm}/{yy}` → `1/10/69`
  - `jobNoDigits`: จำนวนหลักของลำดับ (`1` → `1/69`, `3` → `001/69`)
- เนื่องจากนับใหม่ทุกเดือน เลข `1/69` จึงมีได้หลายใบในปีเดียวกัน (คนละเดือน) ค้นหา `1/69` จะเจอทุกใบ ถ้าต้องการไม่ให้ซ้ำ ให้ใส่ `{mm}` ใน `jobNoFormat`

## การค้นหา
ช่องค้นหาช่องเดียว หาได้จาก **ทะเบียน, ชื่อลูกค้า, เบอร์โทร, เลขตัวถัง, ยี่ห้อ/รุ่น, สี, ช่องทางติดต่ออื่น** หรือ **เลขที่งาน** (เช่น `12/2569` หรือ `012/2569`)
ระบบไม่สนช่องว่างและขีด เช่น `กข1234` จะเจอ `กข 1234` และ `0811112222` จะเจอ `081-111-2222`

## วิธีติดตั้ง

1. สร้าง Google Sheet ใหม่ แล้วตั้งชื่อ เช่น "ฐานข้อมูลอู่"
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในโปรเจกต์ Apps Script
   - แทนที่เนื้อหา `Code.gs` ด้วยไฟล์ `src/Code.gs`
   - กด ➕ → **Script** สร้างไฟล์ `Setup`, `Api`, `CertificateDoc`, `Helpers`, `Auth` แล้ววางเนื้อหาจากไฟล์ `.gs` ชื่อเดียวกัน (ต้องครบทั้ง 6 ไฟล์ .gs)
   - กด ➕ → **HTML** สร้างไฟล์ `Index`, `JavaScript`, `Certificate` แล้ววางเนื้อหาจากไฟล์ `.html` ชื่อเดียวกัน
   - ⚠️ Apps Script ไม่ยอมให้ไฟล์ .gs กับ .html ชื่อซ้ำกัน ไฟล์สคริปต์จึงชื่อ `CertificateDoc` ส่วนไฟล์ HTML ชื่อ `Certificate`
   - เปิด **Project Settings → Show "appsscript.json"** แล้ววางเนื้อหาจาก `src/appsscript.json`
4. กลับไปที่ Google Sheet แล้วรีเฟรช จะมีเมนู **🚗 ระบบอู่ซ่อมรถ**
   - **1) ตั้งค่าเริ่มต้น**: สร้างชีต `Vehicles`, `Repairs`, `Settings` (ครั้งแรกจะให้กดอนุญาตสิทธิ์)
   - **2) เพิ่มข้อมูลตัวอย่าง** (ไม่บังคับ)
5. แก้ข้อมูลร้านในชีต `Settings`
6. ใน Apps Script กด **Deploy → New deployment → เลือกชนิด Web app → Deploy** แล้วคัดลอก URL ไปเปิดใช้งาน (บันทึกไว้ในบุ๊กมาร์กหรือหน้าจอมือถือได้)
   - เมื่อแก้โค้ดภายหลัง ให้ใช้ **Deploy → Manage deployments → ✏️ → Version: New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

> **สร้างสคริปต์แยกที่ script.google.com (ไม่ได้เปิดจากเมนูของชีต)?** ใช้ได้เหมือนกัน แต่จะไม่มีเมนู 🚗 ในชีต ให้เลือกฟังก์ชัน `setup` แล้วกด ▷ Run ใน Apps Script แทน
> - ถ้ามีชีตอยู่แล้ว: ใส่ ID ของชีต (ส่วน `<ID>` ใน `docs.google.com/spreadsheets/d/<ID>/edit`) ใน `const SPREADSHEET_ID = ''` บรรทัดบนๆ ของ `Code.gs` ก่อนรัน
> - ถ้าเว้นว่าง: `setup` จะสร้างชีตใหม่ชื่อ "ฐานข้อมูลอู่ซ่อมรถ" ใน Google Drive ให้ (ลิงก์อยู่ใน Execution log)

> ใช้ [clasp](https://github.com/google/clasp) ก็ได้: `clasp create --type sheets --rootDir src` แล้ว `clasp push`

### สิทธิ์การเข้าถึง: รหัสผ่าน (PIN)
หน้าเว็บป้องกันด้วย **รหัสผ่านเดียวที่ใช้ร่วมกันทั้งร้าน** ไม่ต้องแชร์ชีตหรือเพิ่มอีเมลทีละคน
1. ใส่รหัสในแท็บ `Settings` แถว `accessPin` (อย่างน้อย 4 ตัว แนะนำ 6 ตัวขึ้นไป) ถ้ายังไม่มีแถวนี้ ให้รัน `setup` อีกครั้ง
2. Deploy เป็น Web app ด้วย **Execute as: Me** และ **Who has access: Anyone** (ตรงกับ `appsscript.json`)
   - สคริปต์ทำงานในนามเจ้าของ พนักงานจึง**ไม่ต้องกดอนุญาตสิทธิ์และไม่เห็นคำเตือน "Google hasn't verified this app"**
   - ไม่ต้องล็อกอิน Google เลยก็ใช้ได้ (ไม่มีปัญหาเบราว์เซอร์ที่ล็อกอินหลายบัญชี)
3. ส่งลิงก์ `/exec` และรหัสให้พนักงาน เบราว์เซอร์จะจำการเข้าสู่ระบบไว้ `loginDays` วัน (ค่าเริ่มต้น 30)

- **เปลี่ยนรหัส** (เช่น พนักงานลาออก) = แก้ `accessPin` ทุกเครื่องจะถูกให้ใส่รหัสใหม่ทันที
- ใส่รหัสผิดเกิน 10 ครั้ง ระบบจะล็อกการเข้าสู่ระบบ 15 นาที
- ข้อมูลทั้งหมดปลอดภัยเท่ากับรหัส อย่าใช้รหัสที่เดาง่าย เช่น `1234` หรือ `000000`
- ไฟล์ใบรับรอง Doc/PDF จะถูกสร้างใน Google Drive ของเจ้าของ

## ตั้งค่าใบรับรอง (ชีต `Settings`)

| key | ใช้ทำอะไร |
|---|---|
| `shopName`, `shopAddress`, `shopPhone`, `shopTaxId` | หัวกระดาษ |
| `logoFileId` | อัปโหลดโลโก้ลง Google Drive แล้วใส่ File ID (ส่วน `...` ใน `drive.google.com/file/d/.../view`) |
| `certificateTitle`, `certificateSubtitle` | หัวเรื่องใบรับรอง |
| `certificateText` | ข้อความรับรอง |
| `warrantyText` | เงื่อนไขรับประกัน (เว้นว่าง = ไม่แสดง) |
| `jobNoDigits` | จำนวนหลักของเลขที่ (3 → `001/2569`) |
| `docFont` | ฟอนต์ใน Google Doc (ค่าเริ่มต้น Sarabun) |
| `docFolderId` | โฟลเดอร์เก็บไฟล์ Doc/PDF (เว้นว่าง = สร้างโฟลเดอร์ "ใบรับรองการซ่อมรถ" ให้อัตโนมัติ) |
| `templateDocId` | ใช้แม่แบบ Google Doc ของร้านเอง (ดูด้านล่าง) |

### ใช้แม่แบบ Google Doc ของร้านเอง
ถ้าร้านมีแบบฟอร์มใบรับรองอยู่แล้ว ให้ทำเป็น Google Doc แล้วพิมพ์ตัวแปรในรูป `{{ชื่อตัวแปร}}` ตรงตำแหน่งที่ต้องการ จากนั้นใส่ Doc ID ใน `templateDocId` ระบบจะคัดลอกแม่แบบแล้วแทนค่าให้ทุกครั้ง

| ตัวแปร | ค่า |
|---|---|
| `{{jobNo}}` `{{runNo}}` `{{yearBE}}` | เลขที่/ปี, ลำดับ, ปี พ.ศ. |
| `{{issueDate}}` | วันที่ออกเอกสาร (เช่น 29 กันยายน 2569) |
| `{{customerName}}` `{{phone}}` `{{otherContact}}` | ข้อมูลลูกค้า |
| `{{plate}}` `{{province}}` `{{plateFull}}` | ทะเบียน, จังหวัด, ทะเบียน+จังหวัด |
| `{{brand}}` `{{model}}` `{{brandModel}}` `{{color}}` `{{chassisNo}}` | ข้อมูลรถ |
| `{{mileage}}` | เลขไมล์ (เช่น 85,200 กม.) |
| `{{receivedDate}}` `{{completedDate}}` | วันที่รับรถ / วันที่ซ่อมเสร็จ (รูปแบบไทย) |
| `{{details}}` `{{technician}}` `{{cost}}` `{{note}}` | รายละเอียดงานซ่อม |
| `{{shopName}}` `{{shopAddress}}` `{{shopPhone}}` `{{shopTaxId}}` | ข้อมูลร้าน |
| `{{title}}` `{{subtitle}}` `{{certificateText}}` `{{warrantyText}}` | ข้อความจาก Settings |

## หมายเหตุ
- ข้อมูลทั้งหมดอยู่ใน Google Sheet ของคุณเอง สำรองข้อมูลได้ด้วย **ไฟล์ → ทำสำเนา** หรือดูย้อนหลังด้วย **ประวัติเวอร์ชัน**
- ลบรถจากหน้าเว็บจะลบประวัติการซ่อมของรถคันนั้นทั้งหมดด้วย
- ใบรับรองแสดงชื่อและเบอร์ลูกค้า **ปัจจุบัน** ของรถคันนั้น ถ้ารถเปลี่ยนเจ้าของแล้วแก้ข้อมูลลูกค้า ใบรับรองที่พิมพ์ใหม่ของงานเก่าจะเป็นชื่อเจ้าของใหม่ (ไฟล์ Doc/PDF ที่สร้างไว้แล้วจะไม่เปลี่ยน)
